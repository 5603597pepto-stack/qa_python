# qa_python
# Тесты для приложения BooksCollector

**Объект тестирования:** класс `BooksCollector` (`main.py`)
**Файл с тестами:** `test_main.py`
**Фреймворк:** pytest
**Фикстура:** `collector` — создаёт новый экземпляр класса `BooksCollector()` перед каждым тестом.

Описание реализованных тест-кейсов с указанием тестируемого метода, сценария и ожидаемого результата.


### 1. `test_init_genre_list_contains_all_genres`
- **Метод:** `__init__`
- **Параметризация:** каждый жанр из `['Фантастика', 'Ужасы', 'Детективы', 'Мультфильмы', 'Комедии']`
- **Сценарий:** при создании нового объекта класса список `genre` должен содержать полный набор доступных жанров.
- **Ожидаемый результат:** каждый жанр из доступного списка присутствует в `collector.genre`.

### 2. `test_add_new_book_duplicate_book_not_added_again`
- **Метод:** `add_new_book`
- **Сценарий:** одна и та же книга добавляется два раза.
- **Ожидаемый результат:** в `books_genre` остаётся только одна книга — повторное добавление игнорируется.

### 3. `test_set_book_genre_invalid_genre_not_set`
- **Метод:** `set_book_genre`
- **Параметризация:** жанры `'Роман'`, `'Триллер'`, отсутствующие в списке доступных.
- **Сценарий:** книге пытаются установить жанр, которого нет в `genre`.
- **Ожидаемый результат:** жанр книги остаётся пустой строкой (не изменяется).

### 4. `test_get_book_genre_existing_book_returns_genre`
- **Метод:** `get_book_genre`
- **Параметризация:** каждый жанр из `['Фантастика', 'Ужасы', 'Детективы', 'Мультфильмы', 'Комедии']`
- **Сценарий:** у книги, добавленной в коллекцию, установлен корректный жанр.
- **Ожидаемый результат:** метод возвращает установленный жанр по имени книги — для любого жанра из списка доступных.

### 5. `test_get_books_with_specific_genre_matching_genre_returns_book_list`
- **Метод:** `get_books_with_specific_genre`
- **Параметризация:** пары (жанр, книга) — «Фантастика», «Ужасы», «Мультфильмы»
- **Сценарий:** в коллекции есть книга запрошенного жанра; запрашивается список книг заданного жанра.
- **Ожидаемый результат:** возвращается список, содержащий книгу запрошенного жанра — для нескольких разных жанров.

### 6. `test_get_books_genre_returns_current_books_genre_dict`
- **Метод:** `get_books_genre`
- **Сценарий:** в коллекцию добавлена книга с установленным жанром.
- **Ожидаемый результат:** метод возвращает словарь с ожидаемым содержимым — `{'Веселые истории': 'Комедии'}`.

### 7. `test_get_books_for_children_age_rated_genre_book_excluded`
- **Метод:** `get_books_for_children`
- **Параметризация:** жанры из `genre_age_rating` — «Ужасы», «Детективы»
- **Сценарий:** в коллекции есть книга жанра с возрастным рейтингом.
- **Ожидаемый результат:** список книг для детей пуст — книга с возрастным рейтингом в него не попадает, для обоих жанров из `genre_age_rating`.

### 8. `test_add_book_in_favorites_book_not_in_books_genre_not_added`
- **Метод:** `add_book_in_favorites`
- **Сценарий:** в избранное пытаются добавить книгу, которой нет в словаре `books_genre`.
- **Ожидаемый результат:** список `favorites` остаётся пустым.

### 9. `test_delete_book_from_favorites_existing_book_removed`
- **Метод:** `delete_book_from_favorites`
- **Сценарий:** книга добавлена в избранное, затем удалена из него.
- **Ожидаемый результат:** список `favorites` пустой после удаления.

### 10. `test_get_list_of_favorites_books_returns_only_favorites`
- **Метод:** `get_list_of_favorites_books`
- **Сценарий:** в коллекцию добавлены три книги, из них в избранное добавлены только две.
- **Ожидаемый результат:** метод возвращает список именно тех двух книг, которые были добавлены в избранное, третья (не избранная) книга в результат не попадает.
